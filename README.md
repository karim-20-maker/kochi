# كوتشي — Kochi (Personal fitness & nutrition coach)

تطبيق ويب (PWA) بالعربي: حساب السعرات والماكروز والمياه والتمرين **من غير أي AI**.
الكوتش = (أ) برومبت جاهز لـ ChatGPT المجاني، أو (ب) كوتش حقيقي على واتساب.
الحساب على Firebase، لكن بيانات اليوزر (أكل، وزن، صور، ملف شخصي) بتتخزن على جهازه بس وبتشتغل من غير نت. على السحابة مستند صغير للحساب (الإيميل، الاسم، الهدف، ربط الكوتش) + تقرير الكوتش والرسايل.

## 1) إعداد Firebase (مرة واحدة)
1. https://console.firebase.google.com → Add project.
2. Build → **Authentication** → Sign-in method → فعّل **Email/Password** و **Google**.
3. Authentication → Settings → Authorized domains → أضف `karim-20-maker.github.io`.
4. Build → **Firestore Database** → Create (production mode).
5. Firestore → Rules → الصق محتوى `firestore.rules` → Publish.
6. Project settings → Your apps → Web (`</>`) → انسخ `firebaseConfig`.
7. افتح `firebase-config.js` وحط القيم. (القيم دي مش سر.)

لو `apiKey` فاضي التطبيق بيشتغل في **وضع تجريبي** على الجهاز بس (localStorage).

## 2) الرفع على GitHub
1. https://github.com/karim-20-maker/kochi → Add file → Upload files.
2. اسحب كل محتويات المجلد (مش المجلد نفسه) → Commit.
3. Settings → Pages → Source: Deploy from a branch → `main` / root → Save.
4. الرابط: https://karim-20-maker.github.io/kochi/

## 3) الكوتش الخاص (واتساب)
- **الكوتش:** التقدم ← "أنا كوتش" ← اسمه ورقم واتساب ← يطلع كود دعوة فريد من 8 إلى 10 حروف وأرقام (يقدر يختار بادئة من اسمه ويغيّره). الكود بيتسجل في `coaches/{CODE}` ومينفعش يتكرر.
- **المشترك:** يكتب الكود (أو يفتح رابط `?coach=CODE`) فيظهرله طلب موافقة. الكوتش بيشوف اسم المشترك مش إيميله.
- في تبويب الكوتش: "ابعت تقرير اليوم" أو سؤال ← بيفتح واتساب (`wa.me`) والرسالة مكتوبة، والمشترك يدوس إرسال.
- الاختيار بين ChatGPT / واتساب / الاتنين من تبويب الكوتش.
- الكود فيه اسم ورقم الكوتش بس. مفيش سيرفر وسيط ومفيش بيانات بتتشارك غير اللي المشترك بيبعته بنفسه.
- لسه مفيش داشبورد للكوتش ولا دفع (مؤجلين).

## 4) على الموبايل
افتح الرابط في Chrome → ⋮ → Add to Home screen.

## ملاحظات
- التنبيهات (وجبات/مياه) بوب-أب وقت ما التطبيق مفتوح فقط.
- الأرقام الغذائية تقريبية ومش بديل لاستشارة طبية. تحت 18 سنة: التطبيق ما بيعملش عجز سعرات.
- بحث المنتجات من Open Food Facts (مجاني، محتاج نت).
- لو غيرت ملفات بعد النشر، زوّد `VERSION` في `sw.js` عشان الكاش يتحدث.

## لوحة الأدمن
- الرابط: `/admin.html` (مثلا https://karim-20-maker.github.io/kochi/admin.html). الدخول بحساب جوجل `karim.ledoyen@gmail.com` بس (محمي بالـ rules مش بالصفحة).
- بتعرض: الإيميل، كوتش ولا مستخدم، كود دعوة الكوتش، الكوتش المربوط بكل مشترك، الهدف، تاريخ التسجيل وآخر دخول.
- "مسح البيانات" بيمسح بيانات المستخدم من Firestore. مسح الحساب نفسه (الإيميل) من Firebase Console ← Authentication ← Users.
- الإيميل وآخر دخول بيتسجلوا أول ما المستخدم يفتح النسخة الجديدة.

## لوحة الكوتش (عملائي)
- الكوتش بيسجل بحساب واحد وفيه تبديل فوق: "أنا" / "عملائي".
- المشترك لما يفتح رابط الدعوة بيظهرله طلب موافقة، ولو وافق بيتكتب مستند `shares/{uid}` فيه إجماليات آخر 7 أيام (من غير تفاصيل الوجبات ولا الصور).
- الفصل بيمسح المستند فالكوتش يفقد الوصول فورا.
- الـ rules الخاصة بـ `shares` في `firestore.rules` لازم تتنشر (Publish).


## نسخة التجربة (للأصحاب)
- **ويب:** افتح https://karim-20-maker.github.io/kochi/ . على آيفون: Safari ← مشاركة ← "إضافة إلى الشاشة الرئيسية". على أندرويد: Chrome ← "تثبيت التطبيق".
- **أندرويد (APK):** نزّل `kochi.apk` من صفحة Releases (apk-latest)، اسمح بالتثبيت من مصدر غير معروف. فيه التطبيق كله جواه ويشتغل بدون نت. تسجيل الدخول بجوجل مش شغال جوه الـ APK (استخدم الإيميل والباسورد).
- بيانات حسابك (الاسم والطول والوزن والهدف والتمرين والتفضيلات) بتتحفظ نسخة منها في السحابة، فلو دخلت من موبايل تاني أو اتمسحت بيانات المتصفح مش بيسألك من الأول. السجلات اليومية (أكل، وزن، صور) على جهازك بس وبتروح لو مسحت التطبيق أو غيّرت الموبايل. فيه زرار "تصدير بياناتي" في التقدم.

## المميزات
يلا نطبخ (طبخات بالمقادير والتسوية)، رياضات متعددة (جيم، سباحة، كورة، جري، تنس، بادل...) بأيام ثابتة ومدة وحرق تقريبي، كود الكوتش الفريد، وضع الكوتش.
