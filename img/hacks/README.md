# Recipe photos (optional)

Drop a square JPG named after the recipe slug into this folder and the app shows it automatically
(if the file is missing, the cartoon card is shown instead). Use about 800x800 px, under 150 KB.

Slugs in app order: sahlab, hawawshi, pizza, grape-leaves, eggplant, pepper, potato, zucchini, molokhia, fatta, jelly, gelato, ice-cream, hot-choc, chia, pancakes, latte

Example: img/hacks/hawawshi.jpg
